1.0 Module Overview & Sub-Module List

Travel & Expense — Trip request se reimbursement tak ka poora T&E lifecycle

🎯 Module Purpose

Travel & Expense (T&E) module employee ki business travel request, booking, expense claim aur reimbursement ko end-to-end manage karta hai. Grade-wise entitlement policy, OCR-based bill capture, aur multi-level approval — sab automated, aur Payroll (Module 5) ke saath directly linked for reimbursement disbursement.

📦 8 Sub-Modules

  • 8.1 Travel Request & Booking
  • 8.2 Travel Policy & Entitlement
  • 8.3 Expense Claims & Categories
  • 8.4 Bill/Receipt Management (OCR/GST)
  • 8.5 Approval & Reimbursement Workflow
  • 8.6 Travel Advance Management
  • 8.7 Sector-Specific T&E Configuration
  • 8.8 Travel & Expense Analytics

⚠️ Key Business Rules

  • Travel booking sirf approved travel request ke against ho sakti hai
  • Grade-wise entitlement (flight class, hotel category) hard-enforced, exception ke liye approval mandatory
  • Expense claim sirf valid bill/receipt ke saath submit ho sakta hai (except per-km mileage & fixed DA)
  • Claims above policy threshold auto-route ho jate hain Finance approval ke liye
  • Travel advance ka 100% utilization proof zaroori before next advance request
  • Unspent advance auto-recover hota hai next payroll cycle se agar 30 din mein settle nahi hua
  • GST-eligible bills automatically tag hote hain input tax credit ke liye Finance ko
  • International travel ke liye forex advance aur visa tracking mandatory workflow hai

✅ Key Metrics System Track Karega

  • Total T&E Spend (Dept/Project-wise)
  • Average Reimbursement TAT
  • Policy Violation Rate
  • Pending Advance Aging
  • Budget vs Actual Travel Cost
  • Claim Rejection Rate & Reasons
  • Most Visited Cities/Countries
  • Cost per Trip (avg)

3.0 Sub-Module 8.1 — Travel Request & Booking

Domestic aur international travel request, approval, booking integration

🚀 Travel Request Form

🌍 International Travel — Additional Fields

  • Passport number & expiry date validation
  • Visa requirement check & assistance tracking
  • Forex advance request (currency & amount)
  • Travel insurance auto-linked
  • Country-specific compliance checklist (COVID, entry requirements)

✅ Booking Integration Features

  • Flight/hotel search within policy-compliant options only
  • Preferred vendor/travel agency integration (GDS-linked)
  • Auto e-ticket & itinerary attachment to travel record
  • Calendar block for travel dates (syncs with Leave/Attendance)

⚠️ Approval & Booking Rules

  • Domestic travel: minimum 3 days advance request (except emergency, flagged separately)
  • International travel: minimum 15 days advance request for visa processing time
  • Multi-level approval required above certain trip cost threshold (Manager → HOD → Finance)
  • Booking cannot be confirmed until travel request is approved

6.0 Sub-Module 8.4 — Bill/Receipt Management (OCR/GST)

Mobile camera capture, auto-read amount, GST tagging for input tax credit

📷 OCR Receipt Capture Features

  • Mobile camera scan with auto-crop and enhancement
  • Auto-extraction: Amount, Date, Vendor Name, GST Number
  • Employee reviews & confirms extracted data before submission
  • Blurry/unreadable receipt flagged for manual re-upload
  • Supports multi-page bills (PDF/multiple images)

✅ GST Capture & Input Tax Credit

  • Vendor GSTIN auto-validated against GST portal format
  • GST amount separately captured (CGST/SGST/IGST breakup)
  • GST-eligible bills tagged for Finance's Input Tax Credit (ITC) claim
  • Non-GST registered vendor bills flagged, no ITC eligibility

🧾 OCR Extraction Field Mapping

Bill DateHeader/date stampCross-validated against travel date range

GST AmountTax breakup sectionAuto-split CGST/SGST/IGST if present

🚫 Credit Card Reconciliation

  • Corporate credit card statement auto-imported and matched against submitted claims
  • Unmatched credit card transactions flagged for employee to submit corresponding claim
  • Personal expenses on corporate card flagged for recovery via payroll deduction
  • Reconciliation report generated monthly for Finance review

⚠️ Exception Handling

  • Policy violation claims require written justification from employee
  • Manager can approve minor exceptions (<10% over limit); larger exceptions escalate to Finance
  • Rejected claims can be resubmitted once with corrections, then require HR mediation
  • Repeated policy violations (3+ in a quarter) flagged for HR/manager counselling

✅ Reimbursement Methods

  • Payroll add-on — included in next salary cycle (most common)
  • Direct bank transfer — for urgent/high-value claims, separate from payroll
  • TAT tracking: target 5-7 working days from approval to disbursement
  • Reimbursement status visible real-time to employee (Submitted → Approved → Paid)

8.0 Sub-Module 8.6 — Travel Advance Management

Estimated advance disbursement, utilization tracking, auto-recovery

💵 Travel Advance Request

🔄 Advance Lifecycle

StageRuleSystem Action
Advance RequestMax 80% of estimated trip costBlocked if prior advance unsettled
Advance DisbursedApproved by manager, processed by FinanceLedger entry created, outstanding balance tracked
Trip CompletionEmployee submits expense claimsClaims auto-adjusted against advance
Settlement Window30 days from trip end (policy configurable)Reminder notifications at 15/7/1 days
Unspent Advance RecoveryIf claims < advance amountAuto-deducted from next payroll cycle
Overdue SettlementBeyond settlement window, no claim submittedEscalated to HR/Finance, full recovery triggered

⚠️ Advance Control Rules

  • New advance blocked until previous advance is fully settled (claims submitted or recovered)
  • Advance cannot exceed grade-wise cap regardless of estimated trip cost
  • Cash advances require physical acknowledgment/signature

📊 Advance Aging Tracking

  • 0-15 days: Normal (green)
  • 16-30 days: Reminder sent (yellow)
  • 31+ days: Overdue, recovery initiated (red)

14.0 Database Design — Travel & Expense Module

Key tables aur relationships

-- Travel Request CREATE TABLE travel_requests ( request_id VARCHAR(20) PK, emp_id VARCHAR(20) FK (employees), travel_type ENUM('Domestic','International'), from_city VARCHAR(50), to_city VARCHAR(50), start_date DATE, end_date DATE, purpose VARCHAR(200), project_code VARCHAR(30), status ENUM('Pending','Approved', 'Rejected','Completed') ); -- Entitlement Master CREATE TABLE travel_entitlement ( entitlement_id BIGINT PK AUTO_INCREMENT, grade_band VARCHAR(20), flight_class VARCHAR(30), hotel_category VARCHAR(20), da_metro DECIMAL(8,2), da_nonmetro DECIMAL(8,2) ); -- Travel Advance CREATE TABLE travel_advance ( advance_id VARCHAR(20) PK, emp_id VARCHAR(20) FK, request_id VARCHAR(20) FK, amount DECIMAL(10,2), disbursed_at TIMESTAMP, status ENUM('Outstanding','Settled', 'PartiallySettled','Recovered') );
-- Expense Claims CREATE TABLE expense_claims ( claim_id VARCHAR(20) PK, emp_id VARCHAR(20) FK, request_id VARCHAR(20) FK, total_amount DECIMAL(10,2), advance_adjusted DECIMAL(10,2), net_payable DECIMAL(10,2), status ENUM('Draft','Submitted', 'ManagerApproved','FinanceApproved', 'Rejected','Reimbursed'), submitted_at TIMESTAMP ); -- Expense Line Items CREATE TABLE expense_line_items ( line_item_id BIGINT PK AUTO_INCREMENT, claim_id VARCHAR(20) FK, category VARCHAR(50), expense_date DATE, amount DECIMAL(10,2), gst_amount DECIMAL(8,2), vendor_gstin VARCHAR(15), bill_path VARCHAR(500), is_policy_compliant BOOLEAN ); -- OCR Extraction Log CREATE TABLE ocr_extraction_log ( extraction_id BIGINT PK AUTO_INCREMENT, line_item_id BIGINT FK, extracted_amount DECIMAL(10,2), extracted_date DATE, extracted_vendor VARCHAR(100), confidence_score DECIMAL(4,2) ); -- Reimbursement Batch CREATE TABLE reimbursement_batch ( batch_id VARCHAR(20) PK, run_date DATE, total_claims INT, total_amount DECIMAL(12,2), disbursement_mode ENUM('Payroll','BankTransfer') );
