1.0 Module Overview & Sub-Module List

Leave — Policy configuration se balance settlement tak ka poora process

🎯 Module Purpose

Leave Management module employee ke sabhi leave types — Earned, Casual, Sick, Maternity, Paternity — ko policy-based accrue, apply, approve aur settle karta hai. Indian labour law (Factories Act, Shops & Establishment Act, Maternity Benefit Act) ke hisaab se state-wise aur sector-wise configurable, aur Attendance (Module 3) & Payroll (Module 5) ke saath fully synced.

📦 8 Sub-Modules

  • 4.1 Leave Type Master & Policy Configuration
  • 4.2 Leave Application & Approval Workflow
  • 4.3 Leave Balance & Accrual Engine
  • 4.4 Holiday Calendar Management
  • 4.5 Maternity, Paternity & Statutory Leaves
  • 4.6 Leave Encashment & Carry Forward
  • 4.7 Sector-Specific Leave Configuration
  • 4.8 Leave Dashboard & Analytics

⚠️ Key Business Rules

  • Leave balance se zyada apply nahi ho sakta, unless policy negative balance allow kare
  • Sandwich leave rule: weekly-off/holiday leave ke beech aaye to woh bhi leave count hoga (policy-based)
  • CL aur SL ko clubbed nahi kar sakte 3 din se zyada (company policy dependent)
  • Maternity leave sirf confirmed female employee ko, max 2 surviving children tak full benefit
  • Leave application minimum prior notice ke bina auto-reject (except sick/emergency leave)
  • Approved leave attendance module mein auto-reflect hoga, double deduction nahi hoga
  • Carry-forward leave ki max limit aur expiry date policy se bound hai
  • LOP (Loss of Pay) auto-trigger hota hai jab balance khatam ho jaye aur employee phir bhi absent rahe

✅ Key Metrics System Track Karega

  • Leave Utilization % by type & department
  • Average Leave Balance per Employee
  • Leave Approval TAT (Turnaround Time)
  • Absenteeism Pattern (Monday/Friday leaves)
  • Carry Forward vs Encashment Ratio
  • Maternity/Paternity Leave Compliance
  • LOP Days & Cost Impact
  • Team Coverage Risk (overlapping leaves)

🧮 Encashment Calculation

ComponentFormulaExample
Daily Rate(Basic + DA) ÷ 26(₹40,000 + ₹5,000) ÷ 26 = ₹1,731/day
Encashable DaysBalance above carry-forward cap, or on exitBalance 50, Cap 45 → 5 days encashable
Encashment AmountDaily Rate × Encashable Days₹1,731 × 5 = ₹8,655
Tax TreatmentExempt up to limit u/s 10(10AA); balance taxableAs per current IT slab rules

⚠️ Full & Final Settlement (Exit)

  • All unutilized encashable leave balance auto-calculated on exit
  • Full EL balance (not just above-cap) typically encashable at exit — policy dependent
  • CL/SL generally lapse on exit (not encashable, unless state law mandates)
  • Linked to Exit Management module (Module 10) for F&F processing

✅ Carry Forward Rules Summary

  • EL: Max 45 days carry forward (configurable per company policy)
  • CL/SL: Typically lapse at year-end, no carry forward
  • Comp-off: 90-day rolling validity, not tied to leave policy year
  • Optional Holiday: Unused choices lapse, no carry forward

🏛️ Government / PSU Specific Leave Types

🏥 Healthcare Specific Rules

  • Emergency leave override with mandatory backup arrangement

14.0 Database Design — Leave Module

Key tables aur relationships

-- Leave Type Master CREATE TABLE leave_type_master ( leave_type_id VARCHAR(20) PK, leave_code VARCHAR(10) UNIQUE, leave_name VARCHAR(50), annual_quota DECIMAL(5,2), accrual_frequency ENUM('Monthly','Quarterly', 'Yearly','Event'), max_carry_forward DECIMAL(5,2), is_encashable BOOLEAN DEFAULT FALSE, gender_specific ENUM('All','Male','Female'), is_active BOOLEAN DEFAULT TRUE ); -- Leave Policy (Grade/Location Override) CREATE TABLE leave_policy_rules ( policy_id BIGINT PK AUTO_INCREMENT, leave_type_id VARCHAR(20) FK, grade_code VARCHAR(20), location_id INT FK, quota_override DECIMAL(5,2), min_notice_days SMALLINT, max_consecutive_days SMALLINT, sandwich_rule BOOLEAN DEFAULT FALSE ); -- Holiday Master CREATE TABLE holiday_master ( holiday_id BIGINT PK AUTO_INCREMENT, holiday_name VARCHAR(100), holiday_date DATE, holiday_type ENUM('National','State', 'Company','Optional'), location_id INT FK );
-- Leave Applications CREATE TABLE leave_applications ( application_id VARCHAR(20) PK, emp_id VARCHAR(20) FK (employees), leave_type_id VARCHAR(20) FK, from_date DATE, to_date DATE, no_of_days DECIMAL(4,2), is_half_day BOOLEAN DEFAULT FALSE, reason TEXT, backup_emp_id VARCHAR(20) FK, status ENUM('Pending','Approved', 'Rejected','Cancelled'), approved_by VARCHAR(20) FK, applied_at TIMESTAMP DEFAULT NOW() ); -- Leave Ledger (Balance History) CREATE TABLE leave_ledger ( ledger_id BIGINT PK AUTO_INCREMENT, emp_id VARCHAR(20) FK, leave_type_id VARCHAR(20) FK, txn_type ENUM('Accrual','Availed', 'Encashed','Lapsed','CarriedForward','Adjustment'), txn_date DATE, days DECIMAL(5,2), running_balance DECIMAL(5,2), reference_id VARCHAR(20) ); -- Statutory Leave Events (Maternity etc) CREATE TABLE statutory_leave_events ( event_id BIGINT PK AUTO_INCREMENT, emp_id VARCHAR(20) FK, event_type ENUM('Maternity','Paternity', 'Adoption','Miscarriage'), event_date DATE, child_order TINYINT, entitlement_days SMALLINT, medical_cert_path VARCHAR(500) ); -- Leave Encashment CREATE TABLE leave_encashment ( encashment_id BIGINT PK AUTO_INCREMENT, emp_id VARCHAR(20) FK, leave_type_id VARCHAR(20) FK, days_encashed DECIMAL(5,2), amount DECIMAL(10,2), processed_month VARCHAR(7) );
