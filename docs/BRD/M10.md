## 1.0 Module Overview & Sub-Module List

*Exit Management — Resignation se relieving letter tak ka poora offboarding process*

> **🎯 Module Purpose**
> Exit Management module employee ki resignation submission se lekar notice period, no-dues clearance, Full & Final Settlement (FFS), aur relieving/experience letter tak ka poora offboarding process manage karta hai. Asset (Module 9) & Payroll (Module 5) ke saath directly linked, aur exit interview data se attrition insights generate karta hai.

> **📦 8 Sub-Modules**
> - 10.1 Resignation & Notice Period Management
> - 10.2 Counter Offer & Retention Workflow
> - 10.3 No-Dues Clearance (Multi-Department)
> - 10.4 Exit Interview & Feedback
> - 10.5 Full & Final Settlement (FFS)
> - 10.6 Documentation (Relieving/Experience Letter)
> - 10.7 Sector-Specific Exit Configuration
> - 10.8 Attrition Dashboard & Analytics

> **⚠️ Key Business Rules**
> - Resignation submit hone ke baad notice period auto-calculate hoti hai grade/policy ke hisaab se
> - No-dues clearance sabhi departments (IT, Finance, Admin, Asset, HR) se complete hone ke baad hi FFS process hoga
> - Asset recovery (Module 9) complete nahi hoga to FFS hold rahega
> - FFS calculation mein sabhi pending dues (salary, leave encashment, gratuity, bonus) minus recoveries (loan, asset, notice shortfall)
> - Relieving letter sirf clean exit (no-dues clear + notice period served/waived) ke baad generate hogi
> - Absconding case mein alag workflow trigger hota hai — legal/disciplinary track
> - Exit interview optional hai employee ke liye, lekin HR analytics ke liye completion encourage kiya jata hai
> - FFS payment statutory timeline ke andar hona chahiye (typically 45 days, state-dependent)

> **✅ Key Metrics System Track Karega**
> - Attrition Rate (Voluntary vs Involuntary)
> - Average Notice Period Served vs Policy
> - No-Dues Clearance TAT (Department-wise)
> - FFS Processing TAT
> - Exit Interview Completion Rate
> - Top Exit Reasons (from feedback data)
> - Regretted vs Non-Regretted Attrition
> - Counter Offer Acceptance Rate

## 2.0 Master Exit Flow — End to End

*Resignation se relieving tak — poora lifecycle*

### 🔵 Phase 1: Resignation & Notice Period

1. **Employee Submits Resignation** — 👤 Employee: Reason, last working day proposed
2. **Manager Acknowledges** _(decision)_ — 👤 Reporting Manager: Accept / Discuss / Counter-offer
3. **Notice Period Calculated** — 🤖 System Auto: As per grade/policy (30-90 days)
4. **HR Confirms Acceptance** — 👤 HR Admin: Last working day finalized
5. **✅ Exit Process Initiated** _(success)_ — 🤖 System Auto: Workflow tasks auto-created

### 🟠 Phase 2: Clearance & Knowledge Transfer

1. **Knowledge Transfer Plan** — 👤 Employee + Manager: Handover documentation
2. **Asset Recovery Initiated** — 🤖 System Auto: Trigger to Module 9
3. **No-Dues Clearance Requests** — 🤖 System Auto: IT, Finance, Admin, Library, etc.
4. **Each Dept Clears/Flags** _(decision)_ — 👤 Dept Owners: Sign-off or pending dues raised
5. **Exit Interview Scheduled** — 👤 HR Admin: Online form or 1:1 discussion
6. **✅ Last Working Day** _(success)_ — 🤖 System Auto: System access deactivated

### 🟢 Phase 3: Settlement & Documentation

1. **All Clearances Complete?** _(decision)_ — 🤖 System Auto: Blocking check
2. **FFS Calculation** — 🤖 System Auto: Dues - Recoveries = Net Payable
3. **Finance Approval** _(decision)_ — 👤 Finance Head: FFS sign-off
4. **FFS Payment Processed** — 🤖 System Auto: Bank transfer within statutory TAT
5. **Relieving Letter Generated** — 🤖 System Auto: Signed, dated
6. **Experience Letter Generated** — 🤖 System Auto: Tenure, designation, conduct
7. **✅ Exit Closed** _(success)_ — 🤖 System Auto: Records archived, alumni status set

## 3.0 Sub-Module 10.1 — Resignation & Notice Period Management

*Resignation submission, acceptance, notice period tracking*

**📝 Resignation Submission Form**

- **Resignation Type** *(required)* — _dropdown_; options: Voluntary Resignation, Retirement, Contract End
- **Proposed Last Working Day** *(required)* — _date_; e.g. `2024-03-15`
- **Notice Period (as per policy)** — _text_; e.g. `60 Days`
- **Primary Reason for Leaving** *(required)* — _dropdown_; options: Better Opportunity / Career Growth, Compensation, Relocation, Higher Studies, Personal/Family Reasons, Work Environment
- **Additional Comments** — _textarea_; e.g. `Optional detailed reason`

### 📅 Grade-wise Notice Period Policy

| Grade Band | Notice Period | Buy-out Allowed? | Early Release Approval |
| --- | --- | --- | --- |
| Probationer | 15 Days | Yes | Manager only |
| Band A/B (Junior/Executive) | 30 Days | Yes | Manager + HR |
| Band C (Manager) | 60 Days | Yes (with HOD approval) | HOD + HR |
| Band D/E (Senior Mgmt/Leadership) | 90 Days | Case-by-case | CHRO approval mandatory |

> **⚠️ Notice Period Rules**
> - Notice period auto-calculated from resignation date based on grade policy
> - Early release (reduced notice) requires manager + HR approval, may involve buy-out (salary deduction for shortfall days)
> - Notice period extension possible only with mutual agreement (documented)
> - Absconding case (no notice, unauthorized absence) triggers separate disciplinary workflow

> **🔄 Resignation Withdrawal**
> - Employee can request withdrawal before last working day, subject to manager + HR approval
> - If clearance process already started, withdrawal reverses all pending exit tasks
> - Withdrawal history logged for record-keeping

## 4.0 Sub-Module 10.2 — Counter Offer & Retention Workflow

*Retention conversation, counter offer approval, decision tracking*

1. **Resignation Received** — 👤 Manager: Regretted attrition assessment
2. **Retention Worth Pursuing?** _(decision)_ — 👤 Manager + HR: Critical talent assessment
3. **Retention Conversation** — 👤 Manager/HOD: Understand root cause
4. **Counter Offer Approval** _(decision)_ — 👤 HOD + CHRO: Compensation/role revision
5. **Employee Decision** _(decision)_ — 👤 Employee: Accept / Decline
6. **✅ Resignation Withdrawn** _(success)_ — 🤖 System Auto: Exit process cancelled
7. **❌ Offer Declined** — 🤖 System Auto: Exit process continues

**🤝 Counter Offer Record**

- **Current CTC** — _text_; e.g. `₹18,00,000`
- **Proposed Revised CTC** — _number_; e.g. `2100000`
- **Other Considerations** — _text_
- **Approved By** — _text_; e.g. `HOD + CHRO`
- **Employee Response** — _dropdown_; options: Pending, Accepted, Declined
- **Response Date** — _date_

> **⚠️ Counter Offer Policy Considerations**
> - Counter offer decision restricted to critical/high-performer roles only (not blanket policy)
> - All counter offers tracked for pattern analysis (excessive counter-offering signals retention issues)
> - Accepted counter offers monitored for 6-12 months (research shows high re-attrition risk)
> - Budget impact of counter offer requires Finance visibility for headcount cost planning

## 7.0 Sub-Module 10.5 — Full & Final Settlement (FFS)

*Dues, recoveries, gratuity, PF — final payout calculation*

### 💰 FFS Calculation Components

| Component | Type | Calculation Basis |
| --- | --- | --- |
| Pending Salary (Last Month) | Addition | Days worked in exit month × per-day rate |
| Leave Encashment | Addition | Encashable EL balance × per-day rate (Module 4 sync) |
| Gratuity | Addition | (Last Basic+DA × 15 × Years of Service) / 26, if >5 yrs service |
| Pending Bonus/Incentive | Addition | Pro-rata for period worked, if eligible |
| Notice Period Shortfall Recovery | Deduction | Per-day salary × shortfall days (if early release without buy-out) |
| Asset Recovery Cost | Deduction | From Module 9 — unreturned/damaged assets |
| Outstanding Loan/Advance | Deduction | Remaining balance of employee loans/travel advances |
| TDS on Final Settlement | Deduction | As per applicable tax slab on total taxable component |

**💰 FFS Calculation Sheet**

- **Pending Salary** — _text_; e.g. `₹42,000`
- **Leave Encashment** — _text_; e.g. `₹18,750`
- **Gratuity** — _text_; e.g. `₹1,15,384`
- **Pro-rata Bonus** — _text_; e.g. `₹22,000`
- **Asset Recovery Deduction** — _text_; e.g. `-₹18,500`
- **Outstanding Advance** — _text_; e.g. `-₹8,500`
- **TDS Deduction** — _text_; e.g. `-₹12,400`
- **Net FFS Payable** — _text_; e.g. `₹1,58,734`

> **⚠️ FFS Processing Rules**
> - FFS calculation cannot start until all no-dues clearances are complete
> - Gratuity payable only if service ≥ 5 years (exception: death/disability)
> - Statutory timeline for FFS payment: typically within 45 days of last working day (state-dependent, e.g. Karnataka mandates 2 days)
> - PF withdrawal/transfer processed separately via EPFO portal (employee-initiated, HR facilitates)

> **✅ Approval & Payment Flow**
> - FFS statement reviewed and approved by Finance Head before payment
> - Payment via bank transfer, with detailed FFS statement shared to employee
> - Form 16 for the exit financial year issued separately post year-end
> - PF Form 19/10C guidance provided to employee for withdrawal

### 📄 Exit Document Master

| Document | Purpose | Trigger | Format |
| --- | --- | --- | --- |

**📄 Relieving Letter — Key Fields**

- **Designation** — _text_; e.g. `Senior Analyst`
- **Date of Joining - Last Working Day** — _text_; e.g. `12-Jun-2021 to 15-Mar-2024`

- **Digital Signatory** — _text_; e.g. `HR Head - Auto e-signed`

> **⚠️ Documentation Rules**

> - Absconding cases receive a different document (no relieving letter — service termination record instead)
> - All exit documents digitally signed and stored in employee's permanent record (accessible post-exit via alumni portal)
> - Documents available for re-download by ex-employee for a defined retention period (e.g. 7 years)

## 9.0 Sub-Module 10.7 — Sector-Specific Exit Configuration

*Har industry ki alag exit zaroorat — configurable offboarding templates*

### 🏭 Sector-Wise Exit Matrix

| Sector | Special Requirement | Configuration | Priority |
| --- | --- | --- | --- |
| IT / Software | IP/data security clearance, code repository access revoke | Immediate access revoke on LWD, NDA reminder | Critical |
| Manufacturing / Factory | Factory-specific exit clearance (tools, safety equipment) | Shop-floor asset return checklist | High |
| Healthcare / Hospital | Clinical handover, patient record access revoke | Medical council intimation (if applicable) | Critical |
| BFSI (Banking/Finance) | Regulatory reporting of key personnel exit, fidelity bond closure | Compliance notification to regulator (if senior role) | Critical |
| Sales / Field Force | Client relationship handover, non-compete considerations | Client transition plan mandatory | High |
| Government / PSU | Pension processing, vigilance clearance, government asset return | Pension fund transfer, formal vigilance NOC | Critical |
| Consulting | Client project transition, billing closure | Client notification workflow, project reassignment | High |
| Retail / FMCG | Store-level clearance, cash/inventory reconciliation | Store manager sign-off for cash handlers | Medium |

> **🏛️ Government / PSU — Retirement/Exit Process**
> - Pension processing (if applicable) initiated well before retirement date
> - Vigilance clearance mandatory before final settlement for certain grades
> - Government quarters/accommodation vacation clearance (if provided)
> - Service book updation and PPO (Pension Payment Order) processing

> **💻 IT / Software — Data Security Exit**
> - Immediate revocation of code repository, production system access
> - Data loss prevention (DLP) audit on exit trigger for sensitive roles
> - Non-disclosure/non-compete agreement reminder issued formally
> - Device wipe confirmation before laptop reallocation

## 14.0 Database Design — Exit Module

*Key tables aur relationships*

```sql
-- Exit Master
CREATE TABLE exit_records (
  exit_id           VARCHAR(20) PK,
  emp_id            VARCHAR(20) FK (employees),
  resignation_date  DATE,
  proposed_lwd      DATE,
  confirmed_lwd     DATE,
  exit_type         ENUM('Voluntary','Retirement',
                       'Termination','Absconding'),
  exit_reason       VARCHAR(200),
  is_regretted      BOOLEAN,
  status            ENUM('NoticePeriod','Clearance',
                       'FFSProcessing','Closed')
);

-- Counter Offer
CREATE TABLE counter_offers (
  offer_id          BIGINT PK AUTO_INCREMENT,
  exit_id           VARCHAR(20) FK,
  proposed_ctc      DECIMAL(12,2),
  approved_by       VARCHAR(20) FK,
  employee_response ENUM('Pending','Accepted',
                       'Declined'),
  response_date     DATE
);

-- Department Clearance
CREATE TABLE exit_clearance (
  clearance_id      BIGINT PK AUTO_INCREMENT,
  exit_id           VARCHAR(20) FK,
  department        ENUM('IT','Asset','Finance',
                       'Admin','HR','Manager','Security'),
  status            ENUM('Pending','Cleared',
                       'DuesPending'),
  dues_amount       DECIMAL(10,2),
  cleared_by        VARCHAR(20) FK,
  cleared_at        TIMESTAMP
);
```

```sql
-- Exit Interview
CREATE TABLE exit_interview (
  interview_id      BIGINT PK AUTO_INCREMENT,
  exit_id           VARCHAR(20) FK,
  overall_rating    TINYINT,
  manager_rating    TINYINT,
  growth_rating     TINYINT,
  comp_rating       TINYINT,
  would_recommend   VARCHAR(30),
  open_feedback     TEXT,
  submitted_at      TIMESTAMP
);

-- FFS Calculation
CREATE TABLE ffs_calculation (
  ffs_id            VARCHAR(20) PK,
  exit_id           VARCHAR(20) FK,
  pending_salary    DECIMAL(10,2),
  leave_encashment  DECIMAL(10,2),
  gratuity          DECIMAL(10,2),
  asset_deduction   DECIMAL(10,2),
```
